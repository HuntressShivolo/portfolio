## 👩🏾‍💻 About This Project

This is my personal portfolio website, built entirely from scratch using HTML, CSS, and JavaScript — no frameworks, no libraries, no templates. Every line of code was written by hand.

The portfolio showcases my background as a final-year Cybersecurity student at the Namibia University of Science and Technology (NUST), my technical projects, skills, education, and how to get in touch with me.

---

## ✨ Features

- **Animated constellation background** — 110 star particles that connect with gold lines and react to mouse movement, built with the HTML5 Canvas API
- **Custom cursor** — a gold dot with a lagging ring that follows the mouse and reacts on hover
- **Typewriter effect** — rotating role titles typed and deleted in the hero section
- **Animated skill bars** — fill with a gold-to-rose gradient on scroll
- **Scroll reveal animations** — sections and timeline items fade up as you scroll
- **Full-screen alarm** — featured in the MediTrack project showcase
- **Responsive design** — works on desktop, tablet, and mobile
- **Mobile hamburger menu** — clean collapsible navigation on small screens
- **Dotted highlight box** — styled personal statement section

## 🚀 How to Run Locally

1. Clone this repository
   ```bash
   git clone https://github.com/YOUR-USERNAME/portfolio.git
   ```

2. Open the project folder in VS Code

3. Install the **Live Server** extension in VS Code

4. Right-click `index.html` → click **Open with Live Server**

5. The portfolio opens in your browser at `localhost:5500`

> No installs, no build steps, no dependencies. Just open and run.

## 📌 Projects Featured

### 🛡️ OSSEC-Based Intrusion Prevention System
Designed and implemented a host-based IPS using OSSEC Manager and Agents at NUST. Simulated FTP brute-force attacks from a Windows client and demonstrated automated threat detection with active response — blocking attacking IPs without manual intervention.

**Technologies:** OSSEC · Linux · iptables · Wireshark · Active Response

---

### 💊 MediTrack
A medication adherence web app built in pure HTML, CSS and JavaScript. Features a full-screen alarm with Web Audio API generated sound, streak tracking, 14-day adherence calendar, and browser notification reminders. Zero backend — everything stored in localStorage.

**Technologies:** JavaScript · Web Audio API · localStorage · Notifications API
